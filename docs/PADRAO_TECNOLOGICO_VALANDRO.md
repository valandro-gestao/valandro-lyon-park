# PADRÃO TECNOLÓGICO VALANDRO — Referência

**Status:** Este arquivo **não é mais mantido como fonte oficial** do Padrão Tecnológico Valandro.
**Atualizado em:** 20/08/2026

---

## Onde está a fonte oficial

A versão oficial e versionada do Padrão Tecnológico Valandro vive no repositório corporativo:

**[`valandro-gestao/plataforma-valandro`](https://github.com/valandro-gestao/plataforma-valandro)**

Qualquer decisão compartilhada entre aplicações do portfólio Valandro — **arquitetura, infraestrutura, deploy, autenticação, versionamento e demais padrões tecnológicos** — deve ser consultada nesse repositório, não neste arquivo.

## O que permanece no Lyon Reports

Este repositório mantém em sua própria documentação (`docs/ARQUITETURA.md`, `docs/BANCO_DE_DADOS.md`, `docs/ROADMAP.md` etc.) apenas:

- regras de negócio e decisões específicas do Lyon Reports;
- exceções ao padrão corporativo aplicadas a este projeto, quando existirem, documentadas explicitamente onde a exceção se aplica.

Nada neste arquivo substitui ou compete com o padrão corporativo — evitar duas fontes de verdade sobre o mesmo assunto é o motivo desta mudança.

## Em caso de conflito

Para decisões compartilhadas entre aplicações, **o padrão corporativo em `plataforma-valandro` é a referência**, mesmo que este repositório contenha algo diferente ou desatualizado — salvo quando o Lyon Reports documenta explicitamente, em sua própria documentação, uma exceção deliberada para este projeto.
